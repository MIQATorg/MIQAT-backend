# MIQAT

Open-source, self-hostable, cross-platform time tracking application.

- **Platforms:** Android, iOS, Web, Linux, Windows.
- **Offline-first:** Track time without an internet connection.
- **Smart tracking:** Reminders and forgotten-timer detection.
- **Time blocking:** Pomodoro, countdowns, and custom blocks.
- **Analytics:** Reports and time summaries.
- **Social:** Optional groups for accountability.
- **Goal:** Make time tracking simple and effortless.
